## 上線（3 分鐘）

1. 檔案改名 `index.html`
2. 拖進 [vercel.com/new](https://vercel.com/new)（或 netlify drop）
3. 拿網址
4. 手機 Safari 開 → 分享 → 加入主畫面

全螢幕、沒有網址列，看起來就是 app。

## Demo 動線（照這個走 90 秒）

1. **開場那頁停 3 秒** —— 這是你的安全論述，念出來：「我是雞，不是醫生。」
2. **點螢幕幾下** → 球掉下來、雞跑過去啄。先建立「這是隻活的寵物」。
3. **按 ⚙ 選「完美」**→ 關掉 → 拍任何東西 → 照片飛進雞嘴、咬三下 → 發光放煙火。
4. **再 ⚙ 選「石化」**→ 再拍一張 → 雞變灰、走路變超慢、掉碎屑。
   **這個對比是全場最強的一擊。**
5. **收尾**：「AI 判讀是假的，我今天要測的是這個變形機制好不好笑，不是模型準不準。」

> 如果你要改用真 AI 展示，第 5 點改成：「判讀是真的在跑，但我今天要測的是變形
> 機制好不好笑。」然後把 ⚙ 關掉、直接拍。風險自負 —— 現場網路不穩就會退回 demo 模式。

**⚙ 在右上角，demo 前先按一次確認你選好了。** 沒選就是隨機（或 AI，如果開著）。

## 他一定會問「留存怎麼辦」

你的答案是：變形是累積的，連續石化三天才會解除，解除的那一刻是獎勵。
